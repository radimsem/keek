# Idle Stretches are fast-forwarded, not cut

Cutting every span without an Action gives the cleanest video, but the Verification Video is evidence: a hard cut can drop an Action's delayed effect (an animation, a page load, a toast seconds later) and makes a 20 second hang look instant. The Verification Video keeps about 0.3 s before and 1.5 s after each Action, extends that while the screen is still changing, and shows the remaining Idle Stretches as Fast-forwards labelled with the real time they took. The Raw Recording and Session Timeline are kept beside the edit so any Verification Video can be checked against them. keek's own ffmpeg editor makes this edit until a release of Cua Driver's `recording render` can ([ADR 0009](0009-shared-pieces-go-to-cua-driver.md), [ADR 0013](0013-keek-times-the-session-on-stock-cua-driver.md)).
